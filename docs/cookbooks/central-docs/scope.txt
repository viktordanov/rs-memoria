title: A code change reaches the docs page only through the imported summary
desc: Two folders side by side. Left, src/auth/ is the scope of src/auth/README.md. Any edit to login.rs, such as 30 to 15 minutes, makes the README pending. The README exports a summary. Right, docs/ is the scope of docs/guide.md, which covers 0 source files. One arrow crosses from the left folder to the right: only an edit to the exported summary reaches the guide's import block and makes the guide pending. The guide's link to login.rs is navigation only, so no change travels along it.
