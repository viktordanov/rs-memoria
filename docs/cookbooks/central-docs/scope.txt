title: A docs page sees code changes only through the summaries that it imports
desc: Two panels. Left, docs/guide.md only links src/auth/login.rs, which is outside its scope. When login.rs changes from 30 to 15 minutes, src/auth/README.md is pending and docs/guide.md stays current, so the guide drifts. Right, src/auth/README.md covers login.rs and exports a summary, and docs/guide.md imports it. src/ is still outside the guide's scope, but a change to the summary makes the guide wait and then become pending. Other code edits never reach the guide.
