title: When the summary changes, the README is reviewed first, then the guide is rendered and reviewed
desc: Two columns, src/auth/README.md on the left and docs/guide.md on the right, and four steps in order. 1, the README reviewer edits the exported summary: the README is pending, and the guide becomes pending but waits for the README. 2, the README is reviewed and acknowledged: the README is current, and the guide is still pending but ready, after a render. 3, memoria render copies the new summary into the guide's import block. 4, the guide is reviewed and acknowledged: the guide is current.
---
