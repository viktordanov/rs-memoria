title: A README tree with central guidelines
desc: The root README imports the summaries of the api and web READMEs and links the shared library README. Each README covers its own folder. memoria.toml and docs/writing-guide.md give guidance to every README, and a sidecar file adds guidance for services/api only.
---
«░▒▓█» A README TREE · EACH FOLDER EXPLAINS ITSELF, ONE PLACE HOLDS THE RULES «█▓▒░»

┌─ DOCUMENTS AND COVERAGE ─────────────────────────────────────────────────────────┐
│                                                                                  │
│  README.md ─────────────────────────────────────────── ▓▓▓▓ compose.yaml         │
│   │                                                                              │

│   └──▶ ‹link› ──────────── libs/shared/README.md ───── ▓▓▓▓ libs/shared/         │
│                                                                                  │
│  Each README explains its own folder. The root imports two summaries,            │
│  and the import or the link hands each folder to its README.                     │
