title: Central guidance reaches every README, and a sidecar adds rules for one folder only
desc: The guidance in memoria.toml and the guidance file docs/writing-guide.md apply to all four READMEs: README.md, services/api/README.md, services/web/README.md, and libs/shared/README.md. The sidecar services/api/README.memoria.toml adds guidance to services/api/README.md only.
