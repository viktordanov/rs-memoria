title: A code change reaches the root README only when the exported summary changes
desc: A change to services/api/src/orders.rs makes services/api/README.md pending, and the root README.md waits and stays current. The review asks whether the exported summary is still true. If yes, as for a rename, the reviewer acknowledges no-update and the root stays current: one review. If no, as when the API starts to write orders.log, the reviewer edits the summary and acknowledges updated, memoria render copies the new summary into README.md, README.md becomes pending, and a review of the whole root ends with README.md current: two reviews, in import order.
