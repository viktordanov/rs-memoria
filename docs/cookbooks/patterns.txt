title: Four ways to document a project with Memoria
desc: Four panels. One, AGENTS.md and CLAUDE.md at the root cover justfile and Cargo.toml and name shared section guides. Two, a README tree where the api and web READMEs cover their folders and the root README imports their summaries, with central guidance from memoria.toml. Three, a design document beside the code shares its folder's coverage with the README and maps a section to invoice.rs. Four, a page in a central docs folder cannot see src changes and gets them only through an import from src/README.md.
