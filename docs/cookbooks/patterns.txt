title: Where a document lives decides which documents one code change reaches
desc: Four small file trees, one for each pattern, each with one edited file. Agent instruction files: an edit to justfile makes AGENTS.md, CLAUDE.md, and the root README.md pending, because all three live at the root. README tree: an edit to services/api/src/orders.rs makes only services/api/README.md pending; the root README imports its summary and is reviewed only if that summary changes. Beside the code: an edit to billing/tax.rs makes billing/README.md and billing/design.md pending, because both live in billing/. Central docs site: an edit to src/auth/login.rs makes only src/auth/README.md pending; docs/guide.md imports its summary and is reviewed only if that summary changes.
