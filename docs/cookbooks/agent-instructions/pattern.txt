title: Both agent instruction files name the same two section guides
desc: AGENTS.md and CLAUDE.md each have a commands section and a boundaries section. Both commands sections name the guide docs/templates/agent-commands.md, which asks for the command, directory, when to run it, and its success signal. Both boundaries sections name docs/templates/agent-rules.md, which asks for the rule, its reason, and a safe alternative.
