title: Two agent instruction files share two section guides
desc: AGENTS.md and CLAUDE.md each have a commands section that maps justfile and Cargo.toml and a guide-only boundaries section. Each commands section names the agent-commands guide and each boundaries section names the agent-rules guide. memoria.toml registers both guides, which are never sources or documents.
