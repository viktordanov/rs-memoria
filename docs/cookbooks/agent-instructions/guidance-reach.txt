title: A section guide edit reaches only the documents that name the guide
desc: Two panels compare what memoria guidance --changed lists after one edit. After an edit to project guidance in memoria.toml, it lists all four documents, because every document applies project guidance. After an edit to the agent-commands.md section guide, it lists only AGENTS.md and CLAUDE.md, because only they name that guide. README.md and src/README.md are not listed.
